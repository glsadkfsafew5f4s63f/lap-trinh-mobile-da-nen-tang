EXPO GO - CẤU HÌNH KẾT NỐI API

1. Máy tính chạy Node.js và điện thoại phải cùng mạng LAN.
2. Không dùng localhost trên Expo Go.
3. Lấy IPv4 của máy Windows bằng ipconfig.
4. Ví dụ máy có IP 192.168.1.10:
   API_BASE_URL=http://192.168.1.10:7000/api

Web Admin chạy trên cùng máy có thể dùng:
   http://localhost:7000/api

Các API chính:

POST /auth/login
GET  /auth/me
GET  /catalog/categories
GET  /catalog/brands
GET  /catalog/colors
GET  /catalog/sizes

GET  /cart

DELETE /cart/items/:id
POST /orders/voucher/preview
POST /orders
GET  /orders
GET  /orders/:id
PUT  /orders/:id/cancel
GET  /reviews/product/:productId
POST /reviews
POST /payments/:orderId/retry

POST /user/addresses

DELETE /user/addresses/:id

GET  /admin/users
